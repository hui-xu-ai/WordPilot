# 桌宠皮肤与状态

现有八款：**奶团兔、墨墨猫、浮游鲸、书页灵、栗子柯基、薄荷小龙、枫糖小狐、暮色小鸮**。右键桌宠 → 外观皮肤，或在设置 → 外观中选择；选择会沿用现有机制保存。默认皮肤为奶团兔，未保存尺寸时默认70px；已显式保存的尺寸继续保留。旧皮肤ID读取时回退到奶团兔，不在读取过程中改写用户的真实配置。此前六款旧皮肤资源已移除。

| 状态 | 呈现 | 持续规则 |
|---|---|---|
| 休息 idle | 闭眼、中性领牌，无绿色通过光环 | 等待下一次校对 |
| 检查中 busy | 琥珀色圆环与检查标记、专注表情 | 等待结果 |
| 通过 ok | 绿色圆环、白色勾、笑眼笑嘴 | 约2秒后回到休息 |
| 有建议 error | 珊瑚红提示框、白色叹号、睁眼抬眉 | 保留到应用、忽略或重新校对；收起气泡不清除 |
| 暂停 disabled | 闭眼、中性暂停标记 | 重新启用；仍有未处理建议时恢复提醒 |

新建议到达时角色在画布内轻跳一次，相同结果不重复触发；窗口位置与气泡锚点不随动画移动。校对失败不显示绿色通过。通过结果的旧定时器不会提前结束更新的通过状态。

## 皮肤资源协议

每款为 `src/assets/skins/<id>/skin.json` 加SVG部件：body、状态眼睛、状态嘴型。基准64×64，运行时直接缩放矢量坐标；默认70px，推荐64–96px，小尺寸48px也保留角标。颜色、形状及表情共同传达状态。

新皮肤声明可选的 `"status_overlay": true`，由共用渲染器绘制光环与角标；旧清单缺少该字段时仍按原协议渲染。角色固定配色，仅小配饰可用`$STATE`。角标约位于基准画布右下44–63区域，脸部应避开；绘制范围留边，呼吸幅度0.015。

资源目录：`mochi_bunny`、`ink_cat`、`sky_whale`、`page_spirit`、`chestnut_corgi`、`mint_dragon`、`maple_fox`、`dusk_owl`。现有PyInstaller配置会按目录自动收集新资源；源码更新后，已有exe需要重新打包才能包含新皮肤。
