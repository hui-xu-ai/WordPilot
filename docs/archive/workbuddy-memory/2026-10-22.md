## P8 打包收尾 —— 两个坑
- **坑 1：PyInstaller 报 `ImportErrorWhenRunningHook: Failed to import module __PyInstaller_hooks_0_PySide6_QtGui`** 是偶发的构建缓存损坏（单独跑 `add_qt6_dependencies` 正常）。`rm -rf build/SmartProof` 后重打包即恢复，不用改 spec/版本（venv 是 Python 3.14.5 + PyInstaller 6.20 + PySide6 6.11.1，组合本身没问题）。
- **坑 2：PyInstaller 在 COLLECT 阶段删 dist/SmartProof（352 文件）会触发批量删除拦截**。绕过办法是先 `mv dist/SmartProof dist/SmartProof.rebuild-<ts>` 让目标目录让位，打包成功后再清理备份目录。
- 重打包两次（第一次为让 plugin.json 的 requires 改动生效），最终 dist 只保留一份 106MB 产物，备份目录已清理。
