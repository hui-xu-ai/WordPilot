# ADR-002 插件次要界面：全局右侧可折叠抽屉

状态: accepted（2026-10-24 实现：`dbcd622` 之后的 UI 批次）
日期: 2026-10-24

## 背景
主界面内容区是「一个插件一页」。智能纠错页把**校对状态+开关、校对参数、缓存清洗、API 监控**堆在同一页，
次要信息（参数/监控/清洗）长期占据主区，主次不分；其它插件未来也会遇到同类问题。
用户已明确诉求：**给整个 GUI 加一个右侧可折叠抽屉，插件把主要界面与次要界面分开，默认隐藏次要界面以保持简洁**，
并选择"全局一个、跟随当前页"的粒度。

现状约束：
- 插件 UI 只能通过 `ctx.ui`（`add_page` / `add_tool` / `add_tray_action` / `status`）贡献，**没有"次要区域"概念**；
- 外壳是 `QMainWindow` + 自绘标题栏 + `NavRail` + `QStackedWidget`，内容区右侧目前完全空闲；
- 无边框窗口（外加 ADR 之外的 DWM 阴影）；主题走 QSS 令牌，不许内联样式；
- 插件页惰性构造、可缓存、可随插件停用回收（`_page_widgets` / `retain_only`）。

## 备选
### 备选 A：全局单抽屉 + SDK 贡献点（选中）
`ctx.ui.add_side_panel(title_key, factory, width=320)` 注册**属于当前插件页**的次要面板；
外壳在内容区右侧放一个可折叠容器（QSplitter 或自绘折叠条），跟随当前页显隐，宽度与展开状态落配置。
- 优点：一处实现、风格统一；插件仍只依赖 `ctx`；主次分离是最直接的可视化；默认隐藏满足"简洁"。
- 被否理由：需要**新增 SDK 契约**（三处实现：`UiRegistry`/`NullUiRegistry`/`QtUiRegistry`）与外壳布局改造，改动面最大。

### 备选 B：每个插件页自带右侧栏（插件内部实现）
- 优点：外壳零改动，插件自由。
- 被否理由：每个插件各写一套折叠/记忆/快捷键 ⇒ 风格与行为必然不一致；主次分离的"约定"落不到框架层，新插件不知道该怎么写；与"全局一个"的用户选择直接冲突。

### 备选 C：页内手风琴 / QToolBox 折叠
- 优点：改动最小，不新增契约。
- 被否理由：次要信息仍挤在内容区，只是折叠而非分离；窄窗口下主区被进一步压缩，解决不了"占据空间"的核心诉求。

### 备选 D：QDockWidget 原生停靠
- 优点：Qt 自带折叠/浮出/持久化。
- 被否理由：需要 `QMainWindow` 的停靠体系与自带标题栏，与自绘无边框标题栏冲突；浮出后会脱离窗口层级与阴影治理（我们的 `WindowManager` 不接管 QDockWidget 的浮出窗口），风险高于收益。

## 决策
采用备选 A，范围与契约：
- **SDK**：`ctx.ui.add_side_panel(title_key, factory, width: int = 320, plugin_id: str | None = None)`；
  `NullUiRegistry` 静默丢弃（离屏/冒烟安全）；`QtUiRegistry.retain_only()` 一并清理；`remove_plugin()` 同样清理。
- **外壳**：内容区改 `QHBoxLayout`：左 `QStackedWidget` + 右折叠容器；折叠态只留一条 36px 竖条（含展开按钮与面板标题），
  展开态默认 320px、可拖动、可记忆；**面板归属页 = 注册时所在插件页**，切页时自动换面板/自动收起（无面板的页不显示折叠条）。
- **记忆**：`ui.side_panel.open`（bool，默认 false）、`ui.side_panel.width`（int）。
- **快捷键**：`Ctrl+Shift+B` 切换抽屉（避开 Enter/Esc，符合 ROADMAP P0-3 的键位约束）。
- **首批迁移**：智能纠错页把「校对参数 + 缓存清洗 + API 监控」搬进抽屉，页内只保留状态/开关/摘要。
- **主题**：抽屉分隔线与折叠条只用令牌（`color.bg.subtle` / `color.border`），不写内联样式。

## 后果
- 优点：主次分离统一落到框架层，新插件"知道次要界面放哪"；主区更简洁；未来插件管理/设置也能复用。
- 代价：SDK 契约 +1（需同步 `PLUGIN_GUIDE`、`ARCHITECTURE`、`NullUiRegistry` 与测试）；外壳布局改造；智能纠错页需搬迁控件。
- 风险：
  - QSplitter 与 QStackedWidget 嵌套的尺寸计算（窄窗口下抽屉挤压主区）⇒ 设最小宽度与折叠阈值；
  - 无面板的页必须隐藏折叠条，否则出现"点了没东西"；
  - 插件停用但页面已缓存时，面板要随 `retain_only`/`remove_plugin` 清掉，避免残留旧 handler；
  - 快捷键与 Word 冲突需实测（`keyboard` 库为全局钩子）。
- 验收：单测（SDK 契约/清理/默认折叠）+ 冒烟（有面板页的展开↔收起、切页换面板、无面板页隐藏折叠条）+ 用户桌面验收（拖宽、记忆、快捷键、窄窗口）。
